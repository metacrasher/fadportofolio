# FadXD — Portfolio Website

Website portofolio statis untuk FadXD dengan tema dark premium, aksen ungu, dan gaya modern-futuristik.

## Isi folder
- `index.html` — struktur dan konten website.
- `style.css` — seluruh tampilan, responsif, dan thumbnail proyek berbasis CSS.
- `script.js` — navigasi mobile, animasi saat scroll, tahun otomatis, dan navigasi aktif.

## Menjalankan secara lokal
Buka `index.html` di browser. Website ini tidak memerlukan proses build atau backend.

## Deploy ke GitHub Pages
1. Buat repository baru di GitHub.
2. Unggah `index.html`, `style.css`, `script.js`, dan `README.md` ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu tekan **Save**.

## Penyesuaian sebelum dipublikasikan
- Ganti `hello@fadxd.com` di `index.html` dengan alamat email aktif.
- Ganti tautan kontak atau tambahkan tautan sosial media yang benar.
- Ganti proyek konsep dengan proyek asli jika sudah tersedia.
- Ubah deskripsi dan metadata SEO sesuai identitas Anda.

## Catatan
Thumbnail proyek dibuat dengan HTML/CSS sehingga tidak membutuhkan file gambar eksternal. Font Google Fonts memerlukan koneksi internet; jika offline, website menggunakan font fallback.
